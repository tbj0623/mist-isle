# 雾岛突围 MIST ISLE · v1.5.1 质量补丁

发布日期：2026-11-02。此版本在 v1.5.0 的战术教练基础上修复自动化验收的低帧率误判；战斗规则、功能与联网协议 v3 均未改变。

## 改进

- **稳定的键盘移动验收**：CI 采用软件 WebGL 渲染时，半秒钟墙钟时间不一定推进半秒游戏模拟。键鼠自动测试现在持续按 W 直到角色实际移动超过 1.5 米，超时仍会准确报告输入失效。
- **补全 Esc 暂停回归验证**：过去测试只点暂停菜单按钮，覆盖不到双键盘监听器造成的“暂停弹窗一闪而过”风险。现在测试直接按 Esc 打开、检查时间冻结、再次 Esc 恢复，并继续验证鼠标恢复与退出菜单路径。
- **再次分发 Android 签名测试包**：保持正式发布证书和已有安装更新路径，Android 包版本提升到 1.5.1。没有重新设计游戏机制。

## 验证与范围

- 上一个 CI 运行已通过 Node 22、Node 24 单测和 Android assembleDebug/lint，云端 Playwright 26 项中 25 项通过；唯一失败为低帧率下 500ms 内仅移动 1.17 米的时间假设，不是运行时崩溃。
- 本补丁的目标是使 Windows 和 Linux 低帧率环境的同一场景都有稳定判断标准；CI 结果应以发布后实际运行记录为准。
- 仍为公开测试版：GitHub Pages 仅提供离线 AI 试玩，在线多人需要自部署服务端；Android 尚无应用商店正式上架或大规模真机验收。
