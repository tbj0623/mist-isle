# 雾岛突围 MIST ISLE · v1.5.0 战术教练

发布日期：2026-11-02。基于 v1.4.0 公开测试版升级，二进制协议仍为 **v3**；新增死亡复盘字段通过现有事件扩展区传输，不破坏旧客户端的常规对局数据。

## 本次升级：让玩家知道往哪去、为何失败、下一局怎么变强

1. **战术安全区导航**：在圈外显示八方向、最短进圈距离和当前圈伤；缩圈时优先指向下一安全圈内侧，不再只指向旧圈心。小地图以虚线画出转移方向及箭头，留出约 4 米边界余量。尚未落地、已淘汰与静态训练/虫潮模式不显示误导性的缩圈导航。
2. **战术复盘**：结算页新增“淘汰原因 + 下一局建议”区域。依据服务端权威击杀事件，区分枪击、圈伤、燃烧、手雷爆炸、载具撞击和倒地失血；有攻击者时尽可能显示名字和枪械。低命中率会给出有针对性的短点射建议；胜利另有正向复盘。缺失事件时明确说明未知，不捏造死因。
3. **新手物资寻路**：实战教学进行到“拾取物资”目标时，实时显示最近未拾取物资的方向与距离；小地图绘制金色物资点，玩家靠近后使用交互键。
4. **死亡原因纠错**：修复原先圈伤触发 kill 时总写成 `shot` 的错误，补齐爆炸/燃烧/撞车等伤害的来源类型与攻击者名称。所有判断在共享模拟层执行，浏览器离线与服务端一致。

## 测试与适用范围

- 新增 11 项纯函数与真实模拟/二进制传输测试；覆盖方向计算、未来安全圈、禁用阶段、物资、各类死因及复盘文案。
- 新增 3 项 Playwright 浏览器场景：局内圈外提示、毒圈淘汰战术复盘、844×390 手机横屏复盘布局。
- 已验证 CSS 布局自动检查无控制区重叠，代码静态检查 0 错误（仍有历史警告）。
- Windows 全量 Node 单元测试二次运行 **367/367 通过**；首次在并行打包期间出现 1 项地图性能预算超时，隔离重测 10/10 通过（三图合计 642ms），再次全量运行中预算也通过。云端 CI 作为独立质量门禁。
- 路线是直线方向指示，不是可绕建筑、水域的寻路导航；地图实走与移动端真实机器性能仍需玩家验证。
