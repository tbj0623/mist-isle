# MIST ISLE v1.3.1 · 首次公开测试版

《雾岛突围》是原创低多边形俯视角战术生存竞技游戏，支持浏览器与 Android。

## 本版亮点

- 首次开源：MIT 许可证、第三方许可清单、贡献指南、自动化 CI 与后续路线图。
- 首页“立即试玩”，无需账号或服务器，直接进入离线训练场。
- 新手引导默认推荐训练场；选择其他模式时按钮与实战一致，最后一步直接开战。
- 既有内容：三张程序化地图、18 把武器、载具、空投、缩圈、AI 对手、单人/小队/生存波次，以及权威服务器与 Android WebView 客户端。
- 增加桌面与手机横屏的首局 E2E 测试，改善首次运行与截图验证。

## 下载与试玩

- Android 请下载下面的 `mist-isle-1.3.1-release.apk`（正式签名，Android 8.0+）。
- 浏览器离线试玩：GitHub Pages（仓库首页 README 提供链接；首次部署需要等待 Actions 完成）。
- 下载源码或克隆仓库后运行 `npm ci && npm run build && npm start`，打开 `http://127.0.0.1:8787`。

## 重要说明

这是 **Beta 公开测试版**，不是已完成商店上架验收的商业发行：

- GitHub Pages 只托管静态浏览器端，**不提供公网多人对战服务器**；要多人联机需自行部署 Node.js 服务端。
- 尚缺正式的跨机型真机、长时间发热/耗电、真人武器平衡与公网弱网测试。
- 不带账号、云存档和完整生产级反作弊。默认进度保存在本地。
- 不能以 GitHub 下载量或自动化测试结果代替真机和真人验收。

源码与原创可分发素材采用 MIT 协议。感谢试用并通过 Issues 提交可复现的反馈。
