# MIST ISLE v1.4.0 · 训练场实战教学与质量门禁

发布日期：2026-11-02。基于 v1.3.1 公开测试版迭代，网络协议保持 v3，不增加服务端强制迁移。

## 玩家可感知改进

- 离线训练场新增 **5 项真实操作目标**：移动 5 米、开火、命中敌人、换弹、拾取物资。
- 进度由玩家快照与模拟事件驱动，不靠固定倒计时或无条件自动完成；可乱序记录已经完成的操作。
- 桌面端显示 WASD/鼠标/R/E 提示，手机横屏显示摇杆和屏幕按钮提示。
- 教学可跳过，完成或跳过后记住选择；在「设置 → 重新播放新手引导」可重置。
- 小屏卡片置于准星上方，不遮挡两侧虚拟摇杆；跳过按钮触控高度至少 44px。

## 可靠性与工程改进

- 修正 Linux 软件渲染 CI 的错误 FPS 断言：此前把“主循环持续推进”误要求为 >20 FPS，导致模拟时间正常、页面无异常时仍因 SwiftShader 2 FPS 失败。现以模拟时间、实际帧生成和未处理帧错误判断功能回归；性能需在目标设备单独衡量。
- E2E 和 Android 任务不再使用 `continue-on-error` 掩盖失败；失败会令 CI 正式变红并保留 Playwright trace。
- 新增训练目标纯逻辑单元测试和浏览器/移动端教学专项回归。

## 验证

- Windows 本地：356 项单测通过；构建成功；代码检查无错误（保留已有警告）。
- 训练场首局/引导/教学的 7 项 Playwright 专项测试通过（含 844×390 触控布局）。
- Android 8.0+ 正式签名 APK 已通过本机 Gradle 构建及 `apksigner verify`（证书 CN=MIST ISLE）；Linux CI 结果见 [GitHub Actions](https://github.com/tbj0623/mist-isle/actions)。
