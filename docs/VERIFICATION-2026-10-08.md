## 本轮发现与修复

- 四个 CPU 软件渲染浏览器会严重争用资源，曾发生控制指令到达前角色已死亡、加载期间服务器已推进战局、慢连接断开。增加客户端渲染就绪屏障，保留超时，并将常规交互验证迁回实际可用 GPU。SwiftShader 下四窗口稳定性不是已通过项。
- 快按键丢失：动作加入短时脉冲缓冲；救援使用持续按住，松手清理。
- 旧单人规则的排名、玩家上限、车位所有权不适合四人合作，现已改为小队状态与四座规则。
- 重复全量物资/事件广播：加入差量与范围过滤，重连恢复全量基线。
- 完成战局后退出不再改变已确认胜负；结算会关闭暂停弹窗，避免两个原生 dialog 堆叠卡住退出。
- 游戏模型和效果退出时释放 GPU 资源；三次循环验证内存计数回落。
